# RoleRadar Design System

## Core Identity

RoleRadar is an AI-assisted tactical career intelligence platform designed to help users track, analyze, and optimize their job application pipeline.

The platform should feel:
- intelligent
- operational
- focused
- tactical
- modern
- data-aware

NOT:
- gimmicky
- overly corporate
- overloaded with effects
- “hacker movie” fake UI

---

# UI Philosophy

## Visual Direction

RoleRadar should combine:
- tactical dashboard structure
- modern SaaS clarity
- restrained cyberpunk influence
- aviation/radar inspiration
- operational intelligence systems

Primary inspirations:
- Palantir
- Linear

# Design Principles

## Information First

The UI should prioritize:
- readability
- hierarchy
- fast scanning
- operational awareness

Avoid:
- oversized sections
- unnecessary clutter
- giant walls of text
- excessive animations

---

## Tactical Minimalism

The interface should feel:
- clean
- dark
- intentional
- efficient

Glow effects and animations should be:
- restrained
- meaningful
- signal-driven

NOT constant visual noise.
